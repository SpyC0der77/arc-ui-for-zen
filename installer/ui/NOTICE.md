# Installer mark

The Arc UI for Zen mark combines adapted Arc logo geometry with Zen's concentric-ring logo. Colors and composition were changed for this project.

Arc geometry: Arc / The Browser Company, https://commons.wikimedia.org/wiki/File:Arc_(browser)_logo.svg, identified by Commons as PD-textlogo.

Zen geometry: Zen Browser contributors, https://github.com/zen-browser/branding-archive/blob/main/Official/Word%20Marks/SVG/zen_logo_icon_black.svg.
