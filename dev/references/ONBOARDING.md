# Arc onboarding references

- [Appleosophy, Arc Browser for Mac review, January 2023](https://appleosophy.com/2023/01/02/arc-browser-for-mac/). Welcome screen with a single Start setup action. Local reference: `arc/onboarding/arc-welcome.png`.
- [GIGAZINE, Arc for Windows, May 2024](https://gigazine.net/gsc_news/en/20240501-arc-for-windows). Sequential welcome and setup screens. [Welcome image](https://i.gzn.jp/img/2024/05/01/arc-for-windows/s01.png).

The installer borrows the focused welcome, single primary action, and sequential setup. It keeps this project's lavender palette and Geist font, uses existing installation/profile controls, and does not add Arc accounts or browser imports. Publisher images are development references only, excluded from packages.

The installer mark uses the Arc logo geometry from https://commons.wikimedia.org/wiki/File:Arc_(browser)_logo.svg, by Arc / The Browser Company, recolored to the existing plum/lavender palette. Commons identifies the simple geometric logo as PD-textlogo.

The revised installer mark combines Arc geometry with Zen's three concentric rings from the official branding archive. See installer/ui/NOTICE.md for sources, changes and licensing.
